# Digital Archives and Methods Repository

Welcome to the core repository for the Digital Archives and Methods portfolio of Laura Emilie Hollænder Jensen. This repository contains a collection of portfolio assignments completed for the course. 
### Portfolio 2: Danish Monarchs
* **Directory:** `/Portfolio_2_Danish_Monarchs
* **Project Goal:** Perform data wrangling and basic statistical analysis on a dataset of Danish monarchs. 
* **Packages used:** `googlesheets4` and `leaflet`.
### Portfolio 3: Mapping Danish Market Towns 
* **Directory:** `/Portfolio_3_Interactive_Maps
* **Project Goal:** Learn visualisation techniques through interactive mapping. Harvest historical dataset of Danish market towns (*købstæder*) by cross-referencing public entries on *Lex.dk* and *Wikipedia*.
* **Packages Used:** `leaflet`,  `tidyverse`, `googlesheets4`, `htmlwidgets`
### Portfolio 5: Final Project. Spatial and Temporal Trends in Danish Cultural Heritage Management practices. 
* **Directory:** `Portfolio_5_Final_Project`
* **Project Goal:** Map and analyze the total population of protected buildings in Denmark from 1918 to 2026.
* **Methods Used:** `tidyverse`, `tidygeocoder`, `ggplot2`, `leaflet`, `leaflet.extras`, `htmltools`, `htmlwidgets`, and `mapview`.
